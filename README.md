# Mind & Momentum

A psychological wellness platform designed to help teenagers overcome challenges like unnecessary aggression, lack of concentration in studies, poor diet habits, stress, low motivation, and unhealthy routines through simple guidance, activities, and interactive challenges.

## Features
- **Mental Health & Emotions:** Learn to manage stress, anger, and build emotional intelligence.
- **Study & Concentration:** Improve focus, time management, and memory with proven techniques.
- **Healthy Lifestyle:** Understand the importance of diet, sleep, and exercise.
- **Games & Challenges:** Interactive activities to test memory and build good habits.
- **Psychology Quizzes:** Self-discovery quizzes to understand your stress and focus levels.
- **Progress Tracker:** Track daily mood, study hours, water intake, and sleep.
- **Resources:** Helpful articles and emergency support information.

## Tech Stack
- Flutter (Cross-platform support for Web, Mobile, Desktop)
- Material Design 3

## Setup
```bash
flutter pub get
flutter run
```
